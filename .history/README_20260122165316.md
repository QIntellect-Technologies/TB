# 🩺 TB Healthcare Assistant Chatbot

An AI-powered chatbot that provides comprehensive information about Tuberculosis (TB) using natural language processing and semantic search.

## 🌟 Features

- **Intelligent Q&A**: Ask any questions about TB and get accurate, evidence-based answers
- **Comprehensive Knowledge Base**: Covers symptoms, diagnosis, treatment, prevention, and more
- **Semantic Search**: Uses AI to understand your questions and find relevant information
- **User-Friendly Interface**: Clean, modern Streamlit interface with quick action buttons
- **Educational Content**: Myths vs facts, nutrition guides, and global TB statistics
- **Emergency Resources**: Quick access to helplines and important contacts

## 📋 Topics Covered

- ✅ TB Symptoms & Warning Signs
- ✅ Types of TB (Active vs Latent)
- ✅ Diagnosis Methods (Tests & Procedures)
- ✅ Treatment Options & DOTS Program
- ✅ Drug-Resistant TB (MDR-TB & XDR-TB)
- ✅ Prevention & Precautions
- ✅ Nutrition & Lifestyle Guidance
- ✅ TB Complications
- ✅ TB & COVID-19
- ✅ Global TB Statistics
- ✅ Myths vs Facts

## 🚀 Quick Start

### Prerequisites

- Python 3.10+
- Conda environment (env310tfgpu)

### Installation

1. **Activate your conda environment:**
```bash
conda activate env310tfgpu
```

2. **Install required packages:**
```bash
pip install streamlit sentence-transformers scikit-learn numpy
```

### Running the Chatbot

**Option 1: Simple Version (Recommended for quick start)**
```bash
streamlit run tb_chatbot_simple.py
```

**Option 2: Advanced Version (with LangChain)**
```bash
streamlit run tb_chatbot.py
```

The chatbot will open in your default web browser at `http://localhost:8501`

## 💻 Usage

1. **Start the chatbot** using one of the commands above
2. **Type your question** in the chat input at the bottom
3. **Use quick action buttons** for common questions
4. **Download information** using the sidebar download button
5. **Clear chat history** when you want to start fresh

### Example Questions

- "What are the symptoms of tuberculosis?"
- "How is TB diagnosed?"
- "What is the difference between active and latent TB?"
- "How long does TB treatment take?"
- "What foods should TB patients eat?"
- "How can I prevent TB infection?"
- "Is TB curable?"
- "What is the DOTS program?"

## 🔧 Technical Details

### Technologies Used

- **Streamlit**: Web interface framework
- **Sentence Transformers**: Semantic text embeddings
- **Scikit-learn**: Similarity calculations
- **NumPy**: Numerical operations
- **LangChain** (optional): Advanced AI chains
- **ChromaDB** (optional): Vector database

### How It Works

1. **Knowledge Base**: Comprehensive TB information stored in `tb_knowledge_base.py`
2. **Embeddings**: Text is converted to vector embeddings using Sentence Transformers
3. **Semantic Search**: User queries are matched against knowledge base using cosine similarity
4. **Response Generation**: Relevant sections are retrieved and formatted for display

## 🛠️ Troubleshooting

### Common Issues

**Issue**: `ModuleNotFoundError: No module named 'streamlit'`
**Solution**: Install streamlit: `pip install streamlit`

**Issue**: Model download taking too long
**Solution**: The first run downloads the AI model (~100MB). Be patient or use a faster internet connection.

**Issue**: Port already in use
**Solution**: Run with custom port: `streamlit run tb_chatbot_simple.py --server.port 8502`
